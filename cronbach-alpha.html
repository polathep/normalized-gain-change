Literature Review

Alpha ใช้วัดอะไร และควรระวังอะไร

1. ความหมายและบทบาท

Cronbach's alpha หรือ coefficient alpha เป็นค่าสถิติที่ใช้ประเมิน internal consistency reliability ของแบบสอบถามที่มีหลายข้อคำถาม โดยเฉพาะแบบ Likert scale ที่ต้องการรวมหลาย item เป็นคะแนนรวมของ construct เดียวกัน

2. Alpha ไม่ใช่ validity

Alpha สูงไม่ได้แปลว่าแบบสอบถามวัดถูกเรื่องเสมอไป และไม่ได้พิสูจน์ว่า scale เป็นมิติเดียว ผู้วิจัยจึงควรรายงานหลักฐาน validity และ factor structure ร่วมด้วย

3. Alpha สูงมากอาจไม่ดีเสมอ

ค่า alpha ที่สูงมาก เช่น .95 หรือมากกว่า อาจสะท้อนว่า item หลายข้อถามซ้ำหรือวัด construct แคบเกินไป ทำให้แบบสอบถามยาวขึ้นโดยไม่ได้เพิ่มสารสนเทศใหม่มากนัก

4. ต้องดูรายข้อ

การตัด item ควรพิจารณา corrected item-total correlation, alpha if item deleted, การ reverse score, ความหมายเชิงทฤษฎี และผล factor analysis ถ้ามี

5. ใช้ร่วมกับ omega ได้

วรรณกรรมร่วมสมัยเสนอให้ใช้ McDonald's omega ร่วมกับ alpha โดยเฉพาะเมื่อ item มี factor loading ต่างกัน หรือเมื่อมีโมเดลการวัดรองรับ

Interpretation

เกณฑ์การแปลผลที่ใช้บ่อย

< .60 ต่ำ / ควรปรับปรุง ตรวจ construct, coding และคุณภาพ item
.60-.69 พอใช้ แต่ควรระวัง อาจยอมรับได้ในงานสำรวจเบื้องต้น
.70-.79 ยอมรับได้ เหมาะกับงานวิจัยทั่วไปหลายบริบท
.80-.89 ดี ควรรายงาน item-level statistics ประกอบ
≥ .90 สูงมาก อาจมี item ซ้ำซ้อนหรือวัดแคบเกินไป

ใช้เกณฑ์อย่างยืดหยุ่น

ค่า .70 มักถูกใช้เป็นเกณฑ์ขั้นต่ำในงานวิจัยทั่วไป แต่ไม่ใช่กฎตายตัว ต้องดูจุดประสงค์การใช้เครื่องมือ จำนวน item กลุ่มตัวอย่าง และความเสี่ยงของการตัดสินใจจากคะแนน

Workflow

ขั้นตอนการตัด item อย่างมีเหตุผล

  1. ตรวจทิศทางคะแนนและ reverse score item เชิงลบก่อนคำนวณ alpha
  2. ดู corrected item-total correlation โดยเฉพาะ item ที่ต่ำกว่า .30 หรือติดลบ
  3. ดู alpha if item deleted ว่าการตัด item เปลี่ยนค่า alpha มากเพียงใด
  4. ตรวจเนื้อหาของ item ว่าสอดคล้องกับนิยาม construct หรือไม่
  5. ตรวจ factor structure หากแบบสอบถามอาจมีหลายมิติ
  6. รายงานอย่างโปร่งใสว่า item ใดถูกตัด เหตุผลคืออะไร และ alpha เปลี่ยนอย่างไร

# Normalized Gain and Normalized Change

Interactive Thai-language website for explaining normalized gain and normalized change in pretest-posttest learning assessment.

Created by Polathep Vichitkunakorn (Tee) on 9 May 2026.

## Files

- `index.html` - main website content
- `styles.css` - visual design and responsive layout
- `script.js` - calculator logic and interactive examples

## GitHub Pages

This site is ready to publish with GitHub Pages. Upload these files to a GitHub repository, then enable Pages from the repository settings.
